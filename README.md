
#Agriculture Yield Forecasting

#Project Description
An interactive web dashboard that predicts crop yield based on environmental and soil parameters, and compares multiple machine learning models to identify the best predictor for agricultural planning.


#Objectives
Predict crop yield using rainfall, temperature, humidity, soil pH, and nutrient (N, P, K) data.
Compare ML algorithms (Linear Regression, Ridge, Random Forest, Gradient Boosting, XGBoost) using R² and RMSE.
Visualize climate-yield relationships and simulate scenarios like drought and flood.
Enable data exploration through filterable historical records.


#Technologies Used
HTML5, CSS3, JavaScript
Chart.js (data visualization)
XGBoost, Random Forest, Gradient Boosting, Linear/Ridge Regression (ML concepts)


#Future Enhancements
Connect to a real backend ML model via API.
Integrate live weather and soil sensor data.
Add satellite imagery (NDVI) for better accuracy.
Support multi-language and mobile access.
